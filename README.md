# Probability Lab — Tahap 5.1–5.4

Website pembelajaran peluang berbasis HTML, CSS, dan JavaScript Vanilla.

## Menjalankan
1. Ekstrak ZIP.
2. Buka folder `probability-lab` di VS Code.
3. Jalankan `index.html` dengan ekstensi Live Server (disarankan).

## Sudah dibuat
- Fondasi proyek dan navigasi responsif.
- Home / landing page.
- Materi pembelajaran enam modul.
- Laboratorium: dadu, koin, kartu (jenis/suit), objek berwarna, dan frekuensi relatif.
- Statistik hasil, distribusi frekuensi, dan pembanding peluang teoretis.

## Catatan pembelajaran dan asumsi simulasi
- Kartu disederhanakan menjadi empat jenis/suit dengan peluang 1/4 untuk setiap suit; ini bukan simulasi 52 kartu satu per satu.
- Pengambilan objek menggunakan tiga warna dengan komposisi sama; tiap warna memiliki peluang 1/3.
- Mode frekuensi relatif menggunakan koin seimbang.
- Angka peluang teoretis merupakan model ideal; hasil eksperimen aktual bersifat acak.
- Google Fonts dan MathJax memerlukan koneksi internet.
- Eksplorasi permutasi, evaluasi, dan halaman Tentang lengkap akan dikembangkan pada tahap berikutnya.
